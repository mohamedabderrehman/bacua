# النشر وحل المشكلات

## التاريخ

تطبيق واجهة مصمم بعناية. المصادقة وإجابات المساعد محاكاة؛ لا يُفترض وجود خدمة ذكاء اصطناعي منشورة.

## البيئة المحلية

استخدم اعتماديات Expo SDK 54 المثبتة في القفل. لا يحتاج العرض خادماً أو بيانات مزود. الويب افتراضياً EXPO_PUBLIC_ENABLE_SKIA_WEB=0؛ القيمة 1 لمسار CanvasKit مستقل. يقبل الدخول المحاكى بيانات تجريبية؛ استخدم learner@example.test دون كلمة مرور حقيقية. التخزين محلي في الجهاز أو المتصفح وليس حساباً بعيداً.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

المصادقة وإجابات المساعد محاكاة محلية. البديل الافتراضي هو مسار العرض المدعوم؛ تفعيل EXPO_PUBLIC_ENABLE_SKIA_WEB=1 يختار CanvasKit غير المفحوص مستقلاً. لا ندعي نموذجاً حقيقياً أو أمان حساب بعيد أو مزامنة أجهزة.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
