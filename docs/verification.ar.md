# التحقق من الإصدار الحالي

سجل 2026-10-06 ببيانات محلية مؤقتة. يوثق هذا الملف فحوص التطوير منفصلة عن النشر السابق.

## الفحوص المحلية الناجحة

نجح فحص الأنواع وتصدير Expo الثابت للويب. أمكن أن يدخل محلل Markdown في حلقة لا تنتهي عند وصول عنوان جدول جزئي أثناء البث؛ أُصلح وأضيفت فحوص لكل بادئة. يستخدم عرض الويب البديل الموجود دون Skia. نجح إكمال الرد المحاكى واستعادة المحادثة بعد التحديث والإلغاء. تبقى المصادقة محاكاة ويوضح شريط العرض ذلك. فحص الأجهزة ومسار CanvasKit الاختياري منفصلان ولم يكتملَا.

## الأوامر

```sh
npm ci
npm run typecheck
npm run web
# Static browser preview:
npm run build:web
python -m http.server 8092 --directory dist
```

## حالة CI

سُجلت مسارات GitHub Actions لكن المحاولات الأولى انتهت بـstartup_failure قبل إنشاء أي وظيفة أو ملاحظة فحص. النتائج المحلية أعلاه مستقلة عن CI. لا نعرض شارة نجاح ولم توفر الواجهة المتاحة سبباً تفصيلياً.

## حدود المنصة والتغطية

المصادقة وإجابات المساعد محاكاة محلية. البديل الافتراضي هو مسار العرض المدعوم؛ تفعيل EXPO_PUBLIC_ENABLE_SKIA_WEB=1 يختار CanvasKit غير المفحوص مستقلاً. لا ندعي نموذجاً حقيقياً أو أمان حساب بعيد أو مزامنة أجهزة.

استُخدم PHP 8.4.26 وNode 24.19 وPython 3.12.10 حيث ينطبق. لا يثبت السجل جاهزية إنتاج شاملة أو فحص مزود مدفوع أو جميع المنصات.
